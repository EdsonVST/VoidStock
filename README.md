# 📦 VoidStock

Sistema inteligente de gestão de estoque voltado para laboratórios e equipes acadêmicas de engenharia.

## 🚀 Sobre o projeto

O **VoidStock** é um aplicativo que permite registrar, identificar e localizar componentes de forma automatizada utilizando reconhecimento de imagem.

Ele foi desenvolvido para substituir controles manuais e planilhas, trazendo mais organização, rastreabilidade e eficiência.

## 🎯 Objetivo

Facilitar o controle de estoque em ambientes acadêmicos, evitando:
- Perda de componentes
- Compras duplicadas
- Falta de organização

## 🧠 Funcionalidades

- 📷 Reconhecimento de imagem para identificar itens
- 📍 Localização de componentes no estoque
- 📊 Relatórios de disponibilidade
- 🔄 Controle de entrada e saída
- 🔐 Controle de acesso por usuário
- ⚠️ Alertas de estoque crítico

## 🏗️ Arquitetura

- Backend: C# (.NET 8)
- Banco de Dados: SQL Server
- IA: Azure Cognitive Services / ML.NET
- Mobile/Web: Android + Web App
